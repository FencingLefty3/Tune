
# Tune
A local hosted TV system that lets you upload your own media.







## Features

- Custom channels with your own media.
- Localhost, on your own LAN
- Access from any device with a browser.


## Demo/Web

https://fencinglefty3.github.io/Tune/


## Installation

Download the exe from releases. Open file and your good to go.
